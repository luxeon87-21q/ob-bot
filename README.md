# Бот ордер-блоков 4H для акций США

Ищет ордер-блоки по индикатору **LuxAlgo Smart Money Concepts** (internal и swing ордер-блоки, у каждого сигнала указан вид): логика перенесена с Pine на Python и сверена с независимой реализацией. Бот проверяет акции S&P 500 и Nasdaq-100 после закрытия каждой 4-часовой свечи и пишет в Telegram:

- 🟢/🔴 **сформирован** новый бычий или медвежий ордер-блок;
- 👇/👆 **касание**: цена зашла в зону действующего ордер-блока (предыдущая свеча была вне зоны);
- ❌ **пробит** (mitigated), выключено по умолчанию.

Тикер в сообщении — ссылка на график в TradingView (4H).

**Фильтр по опционам.** Сигналы ордер-блоков приходят только по акциям, у которых открытый интерес опционов (коллы + путы, все экспирации в ближайшие 30 дней) не меньше 5000 контрактов. OI берётся из Yahoo раз в день (`options.py`, кэш `cache/options.json`). Если по акции данных нет, сигнал не отсекается. На сайте есть переключатель «OI опционов ≥ 5000» и столбец «OI 30д» в скринере. Волны Вульфа этим фильтром не ограничиваются.

**Волны Вульфа** — отдельная функция, приходит отдельным сообщением:
- ищутся точки 1–4 по классике Билла Вульфа: сходящийся клин, у бычьей волны точка 3 ниже 1, точка 4 ниже 2, но выше 1 (у медвежьей зеркально);
- 🌊 сигнал — цена дошла до продолжения линии 1–3, это зона точки 5;
- в сообщении цель (линия 1–4 к моменту схождения линий 1–3 и 2–4) и примерное число свечей до неё.
Развороты ищутся с длиной 4 свечи (`WOLFE_PIVOT`), поэтому точка 4 подтверждается через 4 свечи, и сигнал может прийти позже касания.

4H свечи собираются так же, как в TradingView для акций США в основную сессию: **09:30–13:30** и **13:30–16:00** по Нью-Йорку.
Проверки идут в **20:40** и **23:10** по Кишинёву (с поправкой на летнее и зимнее время).

## Сезонность (по понедельникам и пятницам)

`seasonal.py` два раза в неделю (понедельник и пятница ≈15:10 по Кишинёву, `.github/workflows/seasonal.yml`) ищет среди **всех акций США** окна, которые начинаются в ближайшие две недели и из года в год дают ход **≥10%**:

- **Год засчитывается**, если за окно цена коснулась цели (+10% для роста, −10% для падения) раньше, чем ушла против нас на 5%. Путь внутри окна не важен: флэт, затем рывок — тоже успех. Цель и стоп в один день — неудача.
- **Дату окончания не нужно задавать**: для каждой даты старта берётся самое короткое окно (20–90 дней), в котором цель достигалась минимум в 80% лет.
- **Против случайных совпадений**: от 10 до 20 лет истории; «обычно» — как часто такой ход бывает при входе в любой день года; «случайность» — шанс получить столько удачных лет при этой базовой частоте (≤1%); соседние даты старта (±3 дня) тоже должны работать; последние 5 лет — минимум 3 удачных; для сравнения средний ход SPY в эти же даты.
- **Отбор**: цена ≥ $5, средний оборот ≥ $5 млн в день, затем **открытый интерес опционов ≥ 5000** (как у ордер-блоков).
- В сообщении — дата ближайшего **отчёта**; ⚠️ если отчёт попадает внутрь окна.

Отчёт приходит в Telegram (команда `/season` — вкл/выкл), и на сайте есть вкладка «Сезонность» с полосой «по годам».
Настройки — переменные `SEAS_*` в `.env.example`.

```bash
python3 seasonal.py --no-tg                       # полный прогон (20–60 минут), без Telegram
python3 seasonal.py --tickers AAPL,NVDA --no-tg   # быстро на своих тикерах
python3 seasonal.py --ticker NVDA                 # все сезонные окна акции на год
```

## Самурай — продажа путов (по будням, 2 раза в день)

`samurai.py` (`.github/workflows/samurai.yml`) — сканер продажи путов по ТЗ в стиле Option Samurai. Запуск ≈10:30 и ≈15:00 по Нью-Йорку.
Фильтры: капитализация ≥ $2 млрд; EMA 30 выше EMA 50 и EMA 500 (дневки); MACD (12/26/9) выше сигнальной; аналитики Buy/Strong Buy
(средняя оценка Yahoo ≤ 2,5); объём опционов за день ≥ 5000 (коллы + путы, экспирации до 60 дней; утром берётся больший из сегодняшнего и вчерашнего);
IV Rank ≥ 60; вероятность истечь без стоимости ≥ 70% (логнормально по IV контракта); 28–45 дней до экспирации и экспирация раньше отчёта; спред бид/аск < $0,50.
Доход = бид / (страйк − бид), годовая = × 365 / дней.

IV Rank: Eulerpool, если задан секрет `EULERPOOL_KEY`; иначе своя история IV (`cache/iv_history.json`, копится с каждым запуском, считается с 60 дней);
до этого — замена «≈»: где IV30 в годовом диапазоне исторической волатильности HV20. Настройки — переменные `SAM_*`.
Telegram: `/samurai` — вкл/выкл. На сайте — вкладка «Самурай».

## Своя скользящая (по будням)

`ma200.py` (`.github/workflows/ma200.yml`) — у каждой акции ищет среднюю, от которой цена исторически отскакивает: перебираются EMA и SMA 100/150/200,
отдельно на неделях и днях. Касание — минимум свечи дошёл до растущей средней (ближе 0,25 ATR), перед этим цена закрывалась выше неё;
отскок — после касания рост на 2 ATR раньше, чем закрытие ниже MA − 1 ATR. «Своя» — средняя с лучшей долей отскоков (≥ 3 касаний на неделях, ≥ 5 на днях, ≥ 70% отскоков).
Сигнал — цена не дальше 1,5 ATR над своей средней (или под ней не глубже 1 ATR). Все акции США (≥ $5, оборот ≥ $5 млн) + крупные ETF, OI опционов ≥ 1000.
Telegram: только новые подходы (повтор — после ухода дальше 3 ATR), `/ma200` — вкл/выкл. На сайте — вкладка «Скользящие». Настройки — `MA200_*`.

## Скринер опционов (страница options.html)

Отдельная страница сайта в стиле Option Samurai: стратегия Naked PUT, фильтры слева (описание, фундамент, техника, опционы акции,
контракт, доходность), таблица с сортировкой и страницами, подробности по клику, готовые сканы («Самурай (ТЗ)», «Как на видео»,
«Все путы ниже цены») и свои — сохраняются в браузере.

- `optscreen.py --universe` (воскресенье, `opt_universe.yml`) — список акций и ETF с объёмом опционов ≥ 2500 по 3 ближайшим экспирациям.
- `optscreen.py` (будни ≈10:30 и ≈15:00 NY, `samurai.yml`) — все путы этих акций до 70 дней, страйк −40…+15% от цены,
  IV30 / IV Rank, объём опционов, отчёт, аналитики, EMA/MACD/RSI и своя оценка F/G/T (1–10) → `cache/optscreen.json`
  (хранится в кэше Actions, не в репозитории). Затем `samurai.py --from-dataset` строит по ней отчёт «Самурай (ТЗ)» для Telegram.

## Установка (Mac)

```bash
cd путь/к/ob_bot
python3 -m pip install -r requirements.txt
cp .env.example .env
```

1. Создайте бота у @BotFather и вставьте токен в `.env` → `TELEGRAM_TOKEN`.
2. Напишите своему боту `/start`, затем выполните `python3 bot.py --chat-id` и вставьте полученный id в `TELEGRAM_CHAT_ID`.
3. Проверьте связь: `python3 bot.py --test`.

## Запуск

```bash
python3 bot.py --once --dry     # разовая проверка, вывод в консоль (первый раз 3–5 минут, качается история)
python3 bot.py --status NVDA    # действующие ордер-блоки по тикеру — удобно сверить с TradingView
python3 bot.py                  # рабочий режим: работает постоянно
```

Чтобы бот работал, пока Mac не спит:

```bash
caffeinate -i python3 bot.py
```

Если Mac уснёт, пропущенные свечи бот обработает при следующей проверке и пришлёт по ним сигналы.
Для работы 24/7 лучше VPS: подойдёт любой Linux-сервер за $4–5 в месяц, команды те же.

## Веб-версия

```bash
python3 web.py
```

Откройте **http://localhost:8000**. Эта команда заменяет `bot.py`: проверки по расписанию и Telegram продолжают работать, плюс появляется сайт.

- **Сигналы:** лента всех событий (новые OB, касания, пробития) с фильтрами. При первом запуске туда попадают сигналы примерно за последние 2 недели.
- **Скринер:** все акции с расстоянием до ближайшего бычьего и медвежьего ордер-блока. Можно отфильтровать «цена в зоне» и «до зоны ≤ 2%», сортировать по любому столбцу.
- **График:** 4H свечи с зонами ордер-блоков, как в LuxAlgo, и отметками событий. Колесо мыши — масштаб, перетаскивание — прокрутка.
- Кнопка **«Проверить сейчас»** запускает проверку вне расписания.

`python3 web.py --no-tg` запускает сайт без отправки в Telegram.

Чтобы открывать сайт с телефона или держать его на VPS, укажите в `.env` `WEB_HOST=0.0.0.0` и обязательно `WEB_PASSWORD`. Адрес будет `http://IP-компьютера:8000`.

## Сайт в интернете (GitHub Pages), работает без вашего компьютера

Файл `.github/workflows/scan.yml` запускает `build_site.py` на серверах GitHub после каждой 4H свечи (пн–пт). Каждый запуск:
1. скачивает свечи и ищет ордер-блоки;
2. шлёт сигналы в Telegram, если заданы секреты `TELEGRAM_TOKEN` (и по желанию `TELEGRAM_CHAT_ID`; если его нет, бот сам найдёт чат, из которого ему написали `/start`);
3. публикует сайт на `https://<логин>.github.io/ob-bot/`.

**Telegram-бот @OBDen_bot открыт для всех.** Любой может подписаться, у каждого свой режим. Команды обрабатываются раз в 10 минут задачей `.github/workflows/telegram.yml`:
- `/start` — подписаться (по умолчанию режим «только новые ордер-блоки»);
- `/only_new` — только новые ордер-блоки;
- `/all` — новые ордер-блоки и касания;
- `/ob` — ордер-блоки вкл/выкл;
- `/wolfe` — волны Вульфа вкл/выкл (по умолчанию включены);
- `/season` — пятничный отчёт по сезонности вкл/выкл (по умолчанию включён);
- `/settings` — текущий режим;
- `/stop` — отписаться.

Список подписчиков лежит в `cache/tg_settings.json`. Кто заблокировал бота, удаляется из рассылки автоматически.

Запустить проверку вручную: вкладка **Actions** в репозитории → «Проверка ордер-блоков» → **Run workflow**.
GitHub запускает задачи по расписанию с опозданием от нескольких минут до получаса.

## Настройки (`.env`)

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `UNIVERSE` | `sp500,nasdaq100` | списки акций; `file` — свой список из `tickers.txt` |
| `OB_LENGTH` | 5 | длина internal-структуры (swing — 50) |
| `OB_MITIGATION` | Wick | Wick или Close, как в индикаторе |
| `OB_TRACK_LAST` | 5 | сколько последних ордер-блоков каждого вида (internal / swing) видно и отслеживается, как на графике LuxAlgo; 0 — все непробитые |
| `NOTIFY_FORMED / TOUCHED / MITIGATED` | true / true / false | какие сигналы присылать |
| `OI_MIN` | 5000 | минимальный открытый интерес опционов для сигналов OB; 0 — фильтр выключен |
| `WOLFE` | true | искать волны Вульфа |
| `WOLFE_PIVOT` | 4 | сколько свечей с каждой стороны нужно для точки разворота волны |

## Файлы

- `order_blocks.py` — сам индикатор;
- `wolfe.py` — волны Вульфа;
- `data.py` — списки акций и 4H свечи (Yahoo Finance, бесплатно);
- `bot.py` — расписание и Telegram;
- `web.py` + `static/index.html` — веб-версия (внешних библиотек не нужно);
- `build_site.py` + `.github/workflows/scan.yml` — сайт на GitHub Pages;
- `test_order_blocks.py` — проверки: `python3 test_order_blocks.py`;
- `cache/` — свечи и состояние; удалите папку, чтобы начать с нуля;
- `bot.log` — журнал работы.

## Ограничения

- Yahoo даёт часовые свечи максимум за ~2 года, поэтому ордер-блоки старше этого бот не видит. На TradingView можно увидеть очень старый непробитый блок, которого у бота нет.
- Данные Yahoo иногда чуть расходятся с TradingView по объёму, из-за этого редкие ордер-блоки могут отличаться.
- Индикатор LuxAlgo распространяется по лицензии CC BY-NC-SA 4.0: для личного использования можно, для продажи сигналов — нельзя.
